## 3. Local dev: chunk 404s and admin

- **Cause:** Leftover **Serwist** registration and **Cache Storage** entries serving stale or missing responses for **`/_next/static/*`** on **`localhost`**.
- **Fix:** On each dev load, **unregister all service workers** and **delete all `caches`** for the origin (in addition to prior unregister-only logic). README section expanded (chunk 404, Cache storage, **`content.js`** extension note).
