# Worklog — 05-04-2026

## Tasks completed

- **Split PWA (storefront vs staff):** Removed root **`src/app/manifest.ts`**; added **`public/manifest.webmanifest`** and **`public/admin/manifest.webmanifest`** with **`./`** / **`../`** URLs so **`NEXT_PUBLIC_BASE_PATH`** resolves correctly. **`src/app/admin/layout.tsx`** keeps **`metadata.manifest`** → staff file. **Reason:** with **`output: "export"`**, Next’s metadata merge reapplied the root manifest route on admin prerender, so **`out/admin*.html`** still linked **`/…/manifest.webmanifest`** (customer) instead of **`/…/admin/manifest.webmanifest`**.
